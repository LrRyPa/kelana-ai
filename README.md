<h1 align="center">KelanaAI </h1>

<p align="center">
  <b>KelanaAI</b> adalah aplikasi konsol (CLI) berbasis Python yang dirancang untuk membantu pengguna merencanakan itinerary dan ringkasan perjalanan (<i>trip summary</i>) secara praktis dan terstruktur.
</p>

---

## 🚀 Fitur Utama

- **Trip Summary Generator:** Mengompilasi destinasi, negara, durasi, perkiraan budget, hingga bulan perjalanan ke dalam format ringkasan yang rapi.
- **Formatting Budget Otomatis:** Menampilkan angka budget secara terformat beserta simbol mata uang pilihan.
- **Antarmuka CLI Sederhana:** Interaksi berbasis terminal yang ringan, responsif, dan mudah digunakan.

---

## 🛠️ Teknologi & Tools yang Digunakan

- **Bahasa Pemrograman:** Python 3.13.14
- **IDE / Code Editor:** [Kiro](https://kiro.dev/) (AI-powered Code Editor)
- **Version Control:** Git & GitHub
